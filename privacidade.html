Política de Privacidade do Mural

Última atualização: 21 de outubro de 2026.

Quem usa

O Mural é um aplicativo pessoal. O único usuário é o próprio autor. Ele não é oferecido ao público.

Que dados do Google ele acessa

O Mural pede apenas a permissão drive.file do Google Drive. Com ela, só consegue ver e alterar os arquivos que ele mesmo criou no Drive do autor. Não lê nenhum outro arquivo.

Esses arquivos são cópias de segurança, criptografadas no computador do autor antes de serem enviadas. O Google guarda os arquivos, mas não consegue ler o conteúdo.

O que ele não faz

  • Não compartilha, não vende e não transfere dados para terceiros.
  • Não usa dados para publicidade.
  • Não coleta dados de outras pessoas.

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Como revogar o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
